# IPC-7351 — Generic Requirements for Surface Mount Design and Land Pattern Standard (distilled rules)

Provenance: **IPC-7351 (original), February 2005** (title page, PDF p.1;
"Supersedes IPC-SM-782A with Amendments 1 & 2, December 1999"). NOT the
later IPC-7351A (2007) or IPC-7351B (2010). Text cache
`.book-cache/ipc-7351/` (85 pages), sha256
`72ecd2c4bdc60b9d5d151224916d47795789c1f3fa248be87692e14db0de226b`
per `.book-cache/manifest.json`. Distilled 2026-07-12.

**OCR CAVEAT (important):** this cache is RapidOCR over a scanned PDF
(`"ocr": true` in the manifest). Table cells, subscripts, and pitch
labels are frequently garbled (e.g. the Table 3-2 toe-label reads
`"() 01"`, ball-pitch strings mangle). Numeric VALUES were
cross-checked across the ~10 sibling tables that repeat the same
figure; where a value stands alone or looks physically odd it is
tagged **OCR-uncertain**. Before hard-coding any single-cell threshold,
re-open the page. Locators are "PDF p.N"; the printed page number is
**PDF page minus 1** (PDF p.13 = printed p.12).

PCBSmith audit context: our boards are reflow-assembled (the standard's
courtyard values are explicitly reflow-based — Note 3, PDF p.2), mixed
SMT + THT connectors, KiCad-library footprints. The headline question
this file answers: **what density level do our courtyards correspond
to, and what would a "dense mode" knob legitimately buy us?** Verdict
in the audit section: **Density Level B (median/nominal)**, and dense
mode = Level C (0.1 mm excess), costing process window and forcing
qualification testing.

Section map (from cache): 1 scope/classes/levels (PDF p.2-4); 1.5 terms
incl. courtyard definitions (PDF p.5-6); 3.1 tolerance + solder-joint +

(PDF p.16); 3.4.1 component spacing (PDF p.21); 14 BGA (PDF p.62).

## 1. The three density levels and courtyard excess (THE headline payload)

WHERE: definitions PDF p.5 (sect. 1.5, "Courtyard" / "Courtyard
Excess"); level semantics PDF p.3-4 (sect. 1.3.1) and PDF p.16
(sect. 3.1.5.5); the per-family excess VALUES are the bottom row of
each of Tables 3-2 through 3-14 (PDF p.13-15).

**Definition (PDF p.5):** the courtyard is the smallest rectangle giving
"minimum electrical and mechanical clearance" around the combined
component-body AND land-pattern boundary; the **courtyard excess** is
the ring between the circumscribing land/body rectangle and that outer
boundary. Excess "may be different in x and y" and is **added to EACH
SIDE** of the governing dimension (PDF p.12, sect. 3.1.5.1; worked
example PDF p.15: a 14.5 mm extremity + 0.8 mm excess -> 16.1 mm, then
round-up).

**The three levels (PDF p.3-4):**
- **Level A = Maximum (Most) land protrusion** — low-density product;
  developed for **wave/flow** solder of chip + gull-wing parts; widest
  process window. Naming suffix **M** (PDF p.16).
- **Level B = Median (Nominal)** — moderate density; robust **reflow**
  attachment, also OK for wave/reflow of chip + gull-wing. Suffix **N**.
- **Level C = Minimum (Least)** — high density, portable/hand-held;
  smallest land + courtyard. Suffix **L**. Before adopting Level C the
  user "should consider product qualification testing" per Table 3-15
  (PDF p.3).

THRESHOLD — courtyard excess per side, by family (Tables 3-2..3-14):

| Family (task's list mapped to IPC table) | IPC table | Level C (Min) | Level B (Nom) | Level A (Max) |
|---|---|---|---|---|
| Gull-wing >0.625 mm pitch — **SOIC, wide SOP, SOT23/SOT223, connectors** | 3-2 | 0.1 | 0.25 | 0.5 |
| Gull-wing <=0.625 mm pitch — **TSSOP, SSOP, fine SOP** | 3-3 | 0.1 | 0.25 | 0.5 |
| J-lead — SOJ, PLCC | 3-4 | 0.1 | 0.25 | 0.5 |
| **Chip R/C >= 1608 (0603, 0805, 1206...)** | 3-5 | 0.1 | 0.25 | 0.5 |
| **Chip R/C < 1608 (0402, 0201)** | 3-6 | 0.1 | **0.15** | **0.20** |
| MELF (cylindrical end-cap) | 3-7 | 0.1 | 0.25 | 0.5 |
| Bottom-only terminations | 3-8 | 0.1 | 0.25 | 0.5 |
| Leadless chip carrier, castellated (LCC) | 3-9 | 0.1 | **0.15** | **0.20** |
| **Butt (I-lead) joints** | 3-10 | **0.2** | **0.8** | **1.5** |
| Inward gull-wing (tantalum cap) | 3-11 | 0.1 | 0.25 | 0.5 |
| Flat lug leads | 3-12 | 0.1 | 0.25 | 0.5* |
| **Flat No-Lead — QFN, DFN** | 3-13 | 0.1 | 0.25 | 0.5 |
| **SO No-Lead — SON, small QFN** | 3-14 | 0.1 | 0.25 | 0.5 |

\*Table 3-12 note: "depends on thermal requirements."

**The clean story:** courtyard excess is a near-universal
**0.1 / 0.25 / 0.5 mm** (C / B / A), with only three exceptions —
tiny chips (0402/0201, Table 3-6) and castellated LCC (Table 3-9) at
**0.1 / 0.15 / 0.20**, and butt joints (Table 3-10) at a much larger
**0.2 / 0.8 / 1.5** (an I-formed lead needs a big toe/heel fillet).
There is **no dedicated connector/pin-header courtyard table** in this
revision — connectors inherit gull-wing (Table 3-2) or butt-joint
(Table 3-10) values by their lead form.

WHY: excess is the assembly/rework/inspection/test breathing room the
solder-joint math does NOT consume; larger excess = wider placement and
solder process window (PDF p.2 Notes 3-6; PDF p.15 sect. 3.1.5.4). It is
the mechanism by which "clearances between adjacent components" (the
standard's own scope statement, PDF p.2) are guaranteed: non-overlapping
courtyards => land-to-land gap >= excess_A + excess_B.

MACHINE FORM: PCBSmith does NOT compute excess — it *consumes* the KiCad
footprint's `F.CrtYd` layer as `courtyard_hull` (`library.py` `_measure`,
p.397-435) and enforces `courtyard_overlap` in `virtual_drc.py`
(`_check_courtyards`, p.400) with a 0.02 mm shrink so edge-to-edge
placements don't false-positive. KiCad's standard library draws
courtyards to IPC-7351B **nominal (Level B)**. See audit.

APPLICABILITY: reflow assembly (Note 3, PDF p.2 — wave/other processes
"have to be carried out by the user"); heat dissipation and heavy parts
(>weight/land) NOT accounted for — may need larger lands (Notes 5-6);
these are functional/manufacturing clearances, not safety creepage
(that stays IPC-2221 / IEC 60950-62368).

## 2. Land protrusion (toe/heel/side) — only as pad-geometry audit bounds

WHERE: Tables 3-2..3-14 top rows (PDF p.13-15); defined PDF p.12
(Table 3-1: toe = protrusion beyond lead extremity; heel = beyond the
internal lead dimension; side = to either side of the lead).

The land size at each level = component extremity +- the fillet goals
J_T (toe), J_H (heel), J_S (side), combined with tolerances via
`sqrt(C^2 + F^2 + P^2)` (RMS root-sum-square, PDF p.10-11). Only the
numbers that bound a PAD-GEOMETRY audit are worth keeping:

- **Gull-wing / SOIC / SOT (Table 3-2):** toe J_T 0.15 / 0.35 / 0.55;
  heel J_H 0.25 / 0.35 / 0.45; side J_S 0.01 / 0.03 / 0.05 (C/B/A).
- **Chip R/C >= 0603 (Table 3-5):** toe 0.15 / 0.35 / 0.55; heel
  **-0.05 for ALL levels** (land intentionally under the body, i.e.
  no heel protrusion); side -0.05 / 0.00 / 0.05.
- **QFN / Flat No-Lead (Table 3-13):** toe 0.20 / 0.30 / 0.40; heel
  **0.00 all levels**; side **-0.04 all levels** (land narrower than
  the terminal — the check that a QFN pad is *narrower* than the
  package terminal, not wider).
- **Butt joint (Table 3-10):** toe 0.6 / 0.8 / 1.0; heel 0.6 / 0.8 /
  1.0; side 0.1 / 0.2 / 0.3 — why its courtyard is so large.

MACHINE FORM: these are not a check today. The encodable use is a
sanity BOUND on any hand-authored / imported land: a QFN pad whose
copper extends *past* the terminal toe by >0.4 mm, or a chip land with
a positive heel, contradicts IPC-7351 and is likely a footprint bug —
a candidate `land_protrusion_sane` advisory. PCBSmith trusts KiCad
library footprints, so this is a guard for CUSTOM footprints only.

APPLICABILITY: reflow; the fillet goals are "based on industry
empirical knowledge and reliability testing" (PDF p.13) — do not
re-derive, only bound-check.

OCR-uncertain: Table 3-2/3-4 toe label garbles to `"() 01"` (values
0.15/0.35/0.55 confirmed by the identical Table 3-3/3-8/3-12 rows);
Table 3-8 side label reads `"Jg"` (should be J_S).

## 3. Solder-joint goals + placement/fabrication tolerances baked into the levels

WHERE: PDF p.10-12 (sect. 3.1.1.1-3.1.5.1), Table 3-1.

- The land equations are `Zmax = Lmin + 2J + sqrt(C^2+F^2+P^2)`
  (outer), `Gmin = Smax - 2J_H - sqrt(...)` (inner), `Xmax = Wmin +
  2J_S + sqrt(...)` (width) — PDF p.11. C = component tolerance
  (max-min), F = board fabrication tolerance, P = placement-equipment
  accuracy (diameter of true position).
- **Baked-in tolerance assumptions (worked examples, PDF p.10-11):**
  F = **0.1 mm** assumed fabrication tolerance; P = **0.05 mm** assumed
  placement accuracy in the heel example (PDF p.11), but P = **0.2 mm**
  in the Z-dimension example (PDF p.10). These are illustrative
  defaults the standard says the user "may modify based on equipment
  capability" (PDF p.13). **The density level is NOT a different
  F/P** — it is a different solder-fillet GOAL (J) and courtyard
  excess; the same RMS tolerance model runs at all three levels.
- Statistical (RMS) vs worst-case: the standard uses RMS
  "assuming all features will not reach worst case" (PDF p.11); Level A
  effectively buys back margin by targeting a larger fillet.

MACHINE FORM: informational — it explains WHY Level B is the safe
default (nominal fillet + nominal excess absorbs the 0.1 mm fab /
0.05-0.2 mm placement spread most fabs actually hit). If PCBSmith ever
generates land patterns from scratch (today it consumes KiCad's), these
equations + F=0.1/P=0.05 are the defaults to seed. No check today.

APPLICABILITY: assumes even tolerance distribution; user-specific
equipment overrides the F/P defaults.

## 4. Component spacing beyond courtyards (inter-component clearance)

WHERE: PDF p.21 (sect. 3.4.1); scope statement PDF p.2.

- **The courtyard IS the inter-component clearance mechanism** — the
  scope explicitly frames the standard as giving "recommendations for
  clearances between adjacent components" (PDF p.2) via non-overlapping
  courtyards. There is no separate numeric part-to-part table.
- "A minimum inter-package spacing is required to satisfy
  [reliability, manufacturability, testability, repairability]"
  (PDF p.21, sect. 3.4.1.1). Maximum spacing bounded by board area,
  weight, speed.
- High-density reality (PDF p.21, sect. 3.4.1.4): "the spacing between
  lands of different components are often less than 0.2 mm" — i.e.
  Level C packing drives land-to-land gaps below 0.2 mm, which is why
  Level C demands qualification testing.
- Grid: for NEW designs the accepted international grid (IPC-1902) is
  **0.5 mm, subdivided to 0.05 mm** (PDF p.21). Uniform component
  center-point spacing eases assembly (PDF p.20).

MACHINE FORM: `courtyard_overlap` (virtual_drc) already encodes the
non-overlap rule. The 0.5 mm placement grid matches PCBSmith's
metric-snapped PLACEMENTS. A "min land-to-land gap" advisory (warn
when the routed/placed inter-package land gap < 0.2 mm) would flag
Level-C-tight regions the courtyard check alone passes.

APPLICABILITY: all SMT; the <0.2 mm figure is descriptive of
high-density boards, not a floor to design to.

## 5. Zero-orientation, polarity, and naming convention (footprint-parsing relevance)

WHERE: PDF p.16 (naming, sect. 3.1.5.5), PDF p.43 (sect. 8-area
orientation), PDF p.62 (BGA, sect. 14.2.5).

- **Zero orientation (PDF p.43):** "0 degree is the basic orientation
  of the device"; rotational data specified from the 0 position
  **counter-clockwise** (90 / 180 / 270). This matches KiCad's CCW
  convention and PCBSmith's `rotate_offset` (CLAUDE.md: KiCad CCW,
  y-down). Consistent — no adaptation needed.
- **BGA A1 (PDF p.62, sect. 14.2.5):** ball A1 is at the **upper-left
  when viewed from the TOP**; contact pattern defined from the bottom;
  host land pattern is the mirror (A1 again upper-left from top).
  Alpha = rows (vertical, top-to-bottom, letters I/O/Q/S/X/Z omitted);
  numeric = columns.
- **Naming convention (PDF p.16-18):** intelligent names encode
  prefix + pitch + lead-span + pin-qty, e.g. `QFN50P-BodyWxBodyL-PinQty
  +ThermalPad`, `SOIC127P+LeadSpan-PinQty`, `RESC` + metric body,
  `SOT23`. Suffix **L/M/N = Level C/A/B**. **BGA and QFN packages get
  NO L/M/N suffix — they are listed only at the nominal (Level B)
  density** (PDF p.16 note). So a QFN footprint name carries no density
  letter; assume Level B.

MACHINE FORM: if PCBSmith ever parses density from a footprint NAME,
the L/M/N -> C/A/B map is the key (and QFN/BGA => implicitly B). Today
PCBSmith reads geometry, not names, so this only matters for
provenance/labelling of imported parts. Zero-orientation + BGA-A1
already agree with our conventions — a passive confirmation, not a fix.

APPLICABILITY: all SMT; polarity marking (tantalum/diode/IC pin-1)
required in the CAD database for reliable assembly output (PDF p.43).

## Audit vs PCBSmith — which density level are our courtyards?

**Two independent paths, both land on Level B (median/nominal):**

| PCBSmith mechanism | Value | IPC-7351 level | Verdict |
|---|---|---|---|
| KiCad `F.CrtYd` consumed as `courtyard_hull` (library.py `_measure`) | whatever KiCad drew | KiCad std lib = IPC-7351**B** nominal = **Level B**, ~0.25 mm excess | **Level B** — we inherit the library's median courtyard verbatim |
| No-courtyard fallback (virtual_drc `_courtyard_polygon` p.390) | FAB body + **0.25 mm** margin | Level B excess = **0.25 mm** exactly | **Level B** — the fallback constant IS the Level B number (comment even says "standard 0.25mm margin") |
| `BODY_MARGIN_MM` (library.py:253) | 0.4 mm | not an IPC courtyard-excess value | body-bound estimate, NOT a courtyard; unrelated to A/B/C |
| `courtyard_overlap` shrink | 0.02 mm | n/a | float-noise guard; kicad-cli remains authority |

**Verdict: PCBSmith is a Level B (median / nominal) courtyard design**,
consistently, by both the library-consumption path and the explicit
0.25 mm fallback. This is the correct default for reflow assembly.

**Revision honesty:** our cache is the 2005 ORIGINAL; KiCad footprints
follow the later 7351B (2010). The **0.1 / 0.25 / 0.5 mm (C/B/A)**
general excess is stable across 7351 / 7351A / 7351B, so the Level-B
identification holds; the small-chip (0.15/0.20) and butt-joint
(0.8/1.5) exception values should be re-verified against 7351B before
being hard-coded, since fine-pitch/chip tables were the ones that
moved most between revisions.

**What a declared "dense mode" knob would legitimately allow:**
- **Dense mode = Level C (0.1 mm excess).** For the *fallback* path,
  drop the 0.25 -> **0.1 mm** margin. For the *KiCad-courtyard* path,
  either regenerate footprints at Level C or shrink the consumed
  `courtyard_hull` by **0.15 mm per side** (0.25 - 0.1). This tightens
  land-to-land gaps toward the <0.2 mm high-density regime (PDF p.21).
- **What we give up at Level C (state honestly in the review doc):**
  (1) the wider wave/flow-solder and rework/inspection process window
  that Level A/B buy; (2) IPC requires **product qualification testing
  (Table 3-15)** before shipping Level C (PDF p.3) — the pipeline
  cannot self-certify this, so a Level-C board must carry a standing
  `needs_human_review` + a qualification-testing SAFETY-class finding,
  consistent with Law 4. (3) reduced solder-fillet goal J => less
  joint volume => the pipeline should NOT go Level C on
  mechanically-stressed or high-reliability (Class 3) boards.
- **Loose mode = Level A (0.5 mm excess)** is the opposite knob —
  legitimate for wave-soldered THT-heavy or low-density boards; costs
  board area.

**Action items filed:**
1. A `density_level` board-metadata knob (default **B**); dense mode
   sets the fallback margin to 0.1 and shrinks consumed hulls by 0.15,
   and MUST attach a qualification-testing finding (Table 3-15).
2. Re-verify Table 3-6 (0.15/0.20) and Table 3-10 (0.8/1.5) exception
   cells against an IPC-7351B copy before encoding — they are the
   revision-sensitive ones and, in Table 3-10's case, single-source
   in this OCR.

## Top 10 most machine-encodable requirements (ranked)

1. **Courtyard excess = 0.1 / 0.25 / 0.5 mm (C / B / A) per side**
   (Tables 3-2..3-14, PDF p.13-15) — the density-mode knob:
   default B (0.25, = our current fallback + KiCad libs), dense = C
   (0.1). The single highest-value number in this standard for us.
2. **Non-overlapping courtyards = the inter-component clearance rule**
   (PDF p.2, p.21) — already `courtyard_overlap`; keep, and label its
   density level in the review doc.
3. **Level C requires qualification testing (Table 3-15)** (PDF p.3) —
   dense mode must emit a standing `needs_human_review` + qualification
   SAFETY finding; pure honesty, gates the knob (Law 4).
4. **Small-chip / castellated exception 0.1 / 0.15 / 0.20**
   (Tables 3-6, 3-9) — a per-family excess override for 0402/0201 and
   LCC when we generate courtyards; re-verify vs 7351B first.
5. **Butt-joint excess 0.2 / 0.8 / 1.5** (Table 3-10, PDF p.15) —
   large-excess family flag; single-source in OCR, verify before use.
6. **QFN/chip land-protrusion sanity bounds** (Tables 3-5/3-13) —
   heel <= 0 for chips/QFN, QFN side fillet negative: a
   `land_protrusion_sane` advisory for CUSTOM footprints only (KiCad
   parts are trusted).
7. **Land equation seeds F = 0.1 mm, P = 0.05 mm** (PDF p.10-11) —
   defaults the day PCBSmith generates land patterns instead of
   consuming KiCad's; `Zmax = Lmin + 2J + sqrt(C^2+F^2+P^2)`.
8. **0.5 mm placement grid, 0.05 mm subdivision** (PDF p.21) — already
   matches our metric-snapped PLACEMENTS; assert it as a grid check.
9. **Min land-to-land gap advisory (<0.2 mm = Level-C-tight)**
   (PDF p.21) — warn where inter-package land gap drops below 0.2 mm,
   catching Level-C density the courtyard check alone passes.
10. **L/M/N -> C/A/B naming map; QFN/BGA => implicit Level B**
    (PDF p.16) — pure provenance/labelling for imported footprints;
    zero geometry, enables per-part density declaration.

## Extraction notes / limitations

- **Revision:** this is the 2005 ORIGINAL IPC-7351, not A/B. Courtyard
  general values (0.1/0.25/0.5) are revision-stable; exception cells
  (Tables 3-6, 3-9, 3-10) are the ones to re-verify against 7351B,
  which is what KiCad libraries actually follow.
- **OCR-uncertain items flagged (5):** (a) Table 3-2/3-4 toe label
  `"() 01"` garble — values recovered by cross-table agreement;
  (b) Table 3-8 side label `"Jg"`; (c) Table 3-10 butt-joint courtyard
  0.2/0.8/1.5 is single-source here; (d) the two conflicting P
  assumptions (0.05 vs 0.2 mm) are genuine — different worked examples,
  not OCR; (e) BGA ball-pitch strings (PDF p.62) are heavily mangled
  (not needed for our audit).
- **No heat/weight in courtyards** (Notes 5-6, PDF p.2): heavy or
  hot parts may need larger lands than any level provides — the
  standard defers this to the user.
- **No connector/pin-header courtyard table** in this revision;
  connectors map to gull-wing (Table 3-2) or butt-joint (Table 3-10).
- These are functional/manufacturing clearances only — safety creepage
  stays IPC-2221 / IEC 60950-1 / 62368-1 (cross-ref ipc-2221b.md).
