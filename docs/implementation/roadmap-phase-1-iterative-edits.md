## Implemented behavior and ownership

[Native edit adapter](../../src/pcbsmith/kicad/native_edits.py) operates on the saved KiCad object tree. It uses existing parsing/serialization and compares canonical object semantics and stable IDs. It can move/rotate board text and reference text, move/rotate front-side components, replace selected straight segments with bounded polylines, move vias, and change an existing model's xyz offset. It preserves rules, layer/net assignments, widths, drill dimensions, unrelated placement/copper, markings, holes and model fields outside the requested delta.

Moves stretch same-net segment endpoints exactly coincident with affected pad/via centres. Replacement traces retain their connected ends, net, width and layer. Added segments receive deterministic IDs. Locked/unsupported objects and out-of-budget edits are rejected. No generator or autorouter is called by this edit adapter. It may serialize the whole native file; that is a local design delta, not reconstruction of the board.

[Board revision boundary](../../src/pcbsmith/board_revision.py) retains `before/`, `design/`, typed request, actual delta, native check evidence and failure/receipt files. It reuses [project library retention](../../src/pcbsmith/kicad/project_dependencies.py), the existing native check owners, [placement cost extraction](../../src/pcbsmith/placement_repair_transaction.py) for optimization intent and [file transactions](../../src/pcbsmith/operations/file_transaction.py) for recoverable application. The small working-edit journal records accepted requests and retained predecessor locations; it is not a second production/release authority.

`digitally_checked_candidate` and `working_revision_applied` both retain `production_accepted: false`. Model-only candidates check file resolution while preserving unresolved package/visual qualification in the model-preflight report. Existing publication/readiness/routing/release gates remain necessary for stronger status. The native check reports expose ignored rules rather than claiming every possible rule ran.

[Rebuild decision](../../src/pcbsmith/board_rebuild.py) binds the native predecessor and accepted-edit journal to an explicit reason, intent reference, invalidated requirements and considered local alternatives. Exhausted-local-repair claims need hashes of retained failed edit records for that source. Shared generation retains the predecessor context, decision and before/after native object comparison in a fresh candidate root. Missing predecessors with accepted-edit journals and unrecorded rebuilds are rejected. This is decision/provenance enforcement, not human-identity authentication or proof of physical infeasibility.

[Caller audit](../../src/pcbsmith/workflow_entrypoint_audit.py) covers 188 potential writer callers across source and tools, including import aliases, named render/build calls and conservative native-file write matches. [Policy](../board-workflow-entrypoints.json) classifies them as shared boundaries, internal primitives or research/compatibility callers. It does not claim that 188 independent board generators exist. [Audit tool](../../tools/audit_board_workflow.py) runs in all complete verification profiles and with `--checks lint`, including the configured hosted static CI lane. No remote CI run was dispatched. AGENTS.md (local reference `../../AGENTS.md`, not included in this public snapshot) makes the ordinary-path and no-silent-rebuild rules explicit for future work.
