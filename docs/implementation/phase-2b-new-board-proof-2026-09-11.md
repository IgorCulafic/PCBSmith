## Source qualification and limitations

R1 changes from `PR01000101001FA100` to `PR01000102001FA100`. [Vishay's official PR01/02/03 datasheet](https://www.vishay.com/docs/28729/pr010203.pdf), revision 08-Jul-2025, pages 1, 3 and 16, defines ratings, ordering and dimensional bounds. Retained source SHA-256: `1b65216400497850afb3e740f378a10a77cd584809e647ae7fcdb707d9b6a2bc`. The page 16 drawing was visually inspected. Maximum round wire diameter is 0.63 mm; the footprint has nominal 0.8 mm holes. A conservative 8 x 2.5 mm package envelope was screened against the actual saved footprint courtyard. Straight leads must be formed to the project's 10.16 mm pitch; this is an assembly requirement, not a manufacturer fixed-pitch guarantee. Nonpolar terminal numbers 1/2 are CAD conventions. Both old/new source records disclose these assumptions.

The current circuit-specific review (local reference `../../outputs/dividerleaf-2b-2026-09-11/working/substitution-electrical-review.md`, not included in this public snapshot) records loading, tolerance, fault power and operating scope. At 100 kohm load nominal output is 1.6556 V. Across the declared input/resistor/load corners it is 1.552–1.773 V, excluding temperature/aging effects. These are analytical calculations, not measurements or a SPICE simulation. Worst upper-resistor power with output shorted is approximately 13.92 mW at the declared maximum input.

Samtec TSW-102-07-G-S connector sources are retained from the [official catalog](https://suddendocs.samtec.com/catalog_english/tsw_th.pdf). Exact purchased connector geometry and mating fit remain unqualified. Installed/shared pinned assets were reused; no new footprint downloads. The working project retains local schematic/footprint dependencies and qualification sources.
