## Supported contract and use

A `pcbsmith-circuit-patterns-v1` JSON contains the native-netlist evidence ID and one or more explicit functions. Each function records exact parts/pins, distinct high/low rails, manufacturer/source page locators, the operating envelope, support obligations, placement/protection assumptions and remaining physical tests. Required quantities are connector voltage/current; supply-bypass voltage/effective-capacitance/ESR; and indicator current/resistor power. The supply-bypass contract is suitable for a reviewed LDO capacitor requirement; it is not a universal IC bypass model.

Bind the JSON as `evidence_files["circuit-patterns"]` in ordinary engineering inputs. Bind every cited source and native XML normally. Refer to that evidence ID in the applicable mandatory support requirements and retain actual support observations. The native XML hash must match the current pre-placement component inventory. Preparation and publication still own inventory replay and native-currentness; the standalone diagnostic cannot establish either by itself.

Use the existing read-only interface, for example from the repository root:

```powershell
.venv/Scripts/python.exe -B -X utf8 -m pcbsmith.engineering_preview outputs/phase-2c-2026-09-11/pulseleaf-replay --engineering outputs/phase-2c-2026-09-11/pulseleaf-replay/engineering-indicator.json
```

## Real-input replay and limitations

The isolated replay copies retained PulseLeaf engineering sources and reads its exact native XML. The existing engineering consumer and the direct diagnostic both accept the declared indicator screen: current 0–2.651515 mA and resistor power 0–13.920455 mW for 4.75–5.25 V, 2 kΩ ±1%, and a deliberately broad 0–5.25 V forward-drop interval. This is a conservative room/reference-condition DC screen, not brightness, timing, transient or full-temperature qualification. The source notes and bounds are reviewable in the JSON.

Samtec's retained TSW/HTSW sheet p1 gives voltage/current ratings conditional on the mating series. No exact mating connector is selected in the retained project. The newly explicit connector operating-envelope check therefore blocks as unverified; it does not invent a universal header rating. Its p1 also distinguishes TSW/HTSW solder-process compatibility: TSW is listed for lead wave rather than lead-free wave. This does not prove hand soldering is unsuitable; the actual alloy, temperature and dwell require a process decision before assembly. These are procurement/assembly holds, not reasons to reroute the accepted board.

## BenchLeaf capacitor source review

The original R001 and all fabrication/physical holds remain preserved. Microchip DS20001826F (local reference `../../outputs/benchleaf-3v3-r001/engineering/mcp1700.pdf`, not included in this public snapshot), p3, gives a 2.3–6.0 V operating input range; its 6.5 V absolute maximum is not an operating target. Page 11 provides the TO-92 pin map and local input/output capacitor relationships. Page 13, sections 5.1–5.2, describes a 1 µF ceramic input capacitor for most applications up to 100 mA and at least 1 µF output capacitance with 0–2 Ω ESR; ceramic, tantalum and aluminum electrolytic types are listed. Actual lead lengths, source impedance, load and temperature still matter.

WIMA MKS2 (local reference `../../outputs/benchleaf-3v3-r001/engineering/wima-mks2.pdf`, not included in this public snapshot), PDF p1/printed p34, specifies the >1 µF dissipation factor at 1 kHz and +20 °C; the corresponding 10/100 kHz entries are absent. PDF p2/printed p35 gives the selected 2.2 µF 63 V family's 7.2 × 7.2 × 13 mm body, 5 mm pitch and tolerance suffix. Thus the original 1.98 µF initial-tolerance minimum and approximately 0.804 Ω estimate at 1 kHz remain scoped calculations. They do not establish full-frequency regulator stability or behavior over temperature/aging. This is an unverified substitution, not observed oscillation.

| Prospective option | Manufacturer support and tradeoff | Required evidence before a board change |
| --- | --- | --- |
| Retain the exact MKS2 film parts | Existing geometry/polarity simplicity is preserved; Microchip does not specifically validate this film part. | Operating-range impedance and startup/load-step evidence. Do not relabel the single-frequency estimate as a stability proof. |
| Manufacturer-supported ceramic direction | Microchip uses X7R in its p3 test conditions and recommends ceramic for high-frequency input behavior. This is the preferred direction for a future reviewed revision. | Select an exact through-hole-compatible part; prove effective capacitance remains at least the required minimum under tolerance, bias, temperature and aging, plus voltage/ESR/package/pin authority. No exact replacement MPN is approved here. |
| Tantalum or aluminum electrolytic | Explicitly listed output types, potentially compatible with through-hole assembly; introduces polarity and part-dependent ESR. | Exact MPN data, operating-range ESR and capacitance, voltage/surge derating, geometry and assembly polarity. A generic nominal value is insufficient. |

No capacitor is substituted in this phase. An approved exact choice would use the existing same-footprint substitution only if geometry/pins and electrical authority qualify; otherwise use a bounded local/region edit decision. There is no justification for a whole-board rebuild yet.

Physical closure owner is the user or delegated assembler. Required inputs are exact purchased parts, the final revision, a current-limited supply, load and oscilloscope. Preserve the existing bring-up worksheet (local reference `../../outputs/benchleaf-3v3-r001/assembly/bring-up.md`, not included in this public snapshot): input/load sweep, startup/load-step captures, ripple/overshoot, warm-run temperatures and fabrication coupon. Set quantitative transient limits for the actual intended load before measurement; an unfilled worksheet is not evidence. Source files were hash-checked against the original source register; retained identities (local reference `../../outputs/phase-2c-2026-09-11/source-review/source-identities.json`, not included in this public snapshot). Microchip p13 and WIMA p1 were visually inspected as well as text-read; four rendered pages are retained, with no claim that every render was inspected.
