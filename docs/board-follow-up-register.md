# Public board follow-up scope

The public source update does not distribute local board jobs or transfer board approvals. Each new or revised delivery requires current native checks, exact source-bound visual decisions, requested CAM checks and the supported handover command.

- Missing inspection: inspect the existing hash-matching artifacts; do not infer a CAD defect or rerender merely because a decision is absent.
- Confirmed CAD defect: use a bounded source-preserving correction with current verification and retained history.
- Physical qualification: retain the exact board revision, owner, method, acceptance criterion, instruments/parts/process inputs and raw measurements. Wait for those inputs rather than repeating CAD checks on an unchanged hold.
- Optional improvement: reopen a completed board only for a new request, changed input or defect evidence.

Laser trace survival and repeatability, plating shrinkage and barrel continuity, coating alignment, purchased-part fit and circuit operation remain physical tests. Local coupon CAD handovers do not establish those capabilities. See [current state](current-state.md) and [production usage](production-usage.md).
